# GrokSnap

**HONOR AI-кнопка → мгновенное фото → Grok**

Приложение для телефонов HONOR:

1. Назначаешь GrokSnap на AI-кнопку.
2. Нажал → тихо делается фото задней камерой.
3. Фото + текст «Реши задачу на этом фото. Дай пошаговое решение.» отправляется в Grok.

## Сборка APK

После загрузки всех файлов:
1. Перейди во вкладку **Actions**
2. Запусти **Build GrokSnap APK**
3. Скачай артефакт GrokSnap-debug
